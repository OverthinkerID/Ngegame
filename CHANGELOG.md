# Changelog Overthinker-Ngegame

Seluruh perubahan utama proyek **Overthinker-Ngegame** dicatat pada berkas ini mengikuti format *Semantic Versioning*.

## [0.1.0] - 2026-11-21

### Ditambahkan
- **Phase 1–11**: Fondasi monorepo Electron + React + TypeScript + Node.js + Python AI Worker + Prisma SQLite, pemindai Steam, AI Vision, AI Brain, Game Controller aman, dan AI Voice Engine Indonesia (VoxCPM 2.0 / F5-TTS).
- **Phase 12–14**: Game Adaptation Engine, AI Runtime Orchestration, profil kalibrasi Stardew Valley, dan tangkapan layar jendela macOS/Windows.
- **Phase 15**: OBS WebSocket v5, YouTube Live, Twitch, Multistream, Narasi Suara Siaran, Asisten Siaran AI, dan Analitik Siaran 10 tab.
- **Phase 17**: Sistem Auto Update In-App berbasis `electron-updater` & GitHub Releases (`OverthinkerID/Ngegame`), `Settings -> Pembaruan`, backup SQLite otomatis sebelum install, pemeriksaan kompatibilitas Python Worker & Prisma, riwayat pembaruan, pembatalan/coba ulang unduhan, dan log pemulihan.
