Overthinker Studio • Desktop AI Gaming & Streaming Center

Kendali AI Gaming, Visi Layar & Studio Siaran dalam Satu Aplikasi

Ngegame (Overthinker-Ngegame) adalah aplikasi desktop lintas platform untuk gamer dan kreator konten yang menggabungkan pemindaian pustaka Steam, pengamatan layar game real-time, penalaran AI dengan pengawasan manusia L1/L2/L3, narator suara VoxCPM 2.0 Bahasa Indonesia, serta kendali OBS Studio WebSocket v5.

Apa Itu Ngegame?

Dirancang oleh Overthinker Studio agar AI dapat mengamati game, membantu aksi secara aman, dan mengomentari permainan saat live streaming.

01 • Pustaka & Adaptor

Deteksi Steam & Profil Game

Memindai game Steam lokal secara otomatis dan menerapkan profil strategi/kontroler aman (allowlist) per genre tanpa meminta kata sandi Steam Anda.

02 • AI & Pengawasan Manusia

Kendali Bertingkat L1 / L2 / L3

AI membaca layar melalui Python Vision Worker (Ollama lokal atau Cloud LLM) dengan kontrol manusia penuh: L2 Wajib Persetujuan, Takeover, dan Emergency Stop instan.

03 • Studio Suara & Siaran

OBS WebSocket & VoxCPM 2.0

Menghubungkan OBS Studio untuk kontrol adegan dan pratinjau output, menyimpan Stream Key YouTube/Twitch di OS Keychain/Credential Manager, serta komentar suara Bahasa Indonesia.

Panduan Konfigurasi Lengkap

Ikuti panduan di bawah ini bila aplikasi menampilkan pesan perlu konfigurasi OBS, kunci siaran, Steam, atau izin macOS.

1. Setup OBS Studio, YouTube Live, & Twitch

  1. Buka OBS Studio 28+ → Tools → WebSocket Server Settings → centang Enable WebSocket server pada port 4455.
  2. Di menu Studio Siaran pada Ngegame, klik Hubungkan OBS WebSocket.
  3. Salin Stream Key dari YouTube Studio atau Twitch Creator Dashboard ke panel Manajer Kredensial sebelum menekan Mulai Siaran.

2. Izin Wajib macOS (System Settings)

  1. Buka System Settings → Privacy & Security.
  2. Aktifkan Ngegame di Screen & System Audio Recording untuk Monitor Visi.
  3. Aktifkan Ngegame di Accessibility dan Input Monitoring agar Kendali AI dapat mengirim input aman saat diizinkan.

3. Setup Pustaka Game Steam

  1. Pastikan Steam Client sudah terpasang di perangkat Anda.
  2. Buka menu Pustaka Game di Ngegame lalu klik Pindai Pustaka.
  3. Ngegame hanya membaca berkas appmanifest_*.acf lokal tanpa meminta login Steam.

4. Konfigurasi AI Brain (Ollama / OpenAI)

  • Ollama (Lokal): Jalankan layanan Ollama lokal untuk penalaran gratis di perangkat sendiri.
  • OpenAI (Cloud): Opsi cadangan dengan kunci API pribadi.
  • Gunakan mode L2 Wajib Persetujuan untuk meninjau setiap aksi AI sebelum dijalankan.

5. Studio Suara AI (VoxCPM 2.0)

  • Gunakan panel Sampel Cloning Suara untuk memutar 3 preset suara Bahasa Indonesia atau mengunggah audio referensi (.wav/.mp3).
  • Jika server VoxCPM 2.0 lokal belum aktif, aplikasi tetap aman dengan suara cadangan lokal.
