Overthinker Studio • Desktop AI Gaming & Streaming Center

Kendali AI Gaming, Visi Layar & Studio Siaran dalam Satu Aplikasi

Ngegame (Overthinker-Ngegame) adalah pusat kendali desktop lintas platform yang memadukan pemindaian pustaka Steam, pengamatan layar game real-time, penalaran AI dengan pengawasan manusia L1/L2/L3, narator suara VoxCPM 2.0 Bahasa Indonesia, dan otomasi OBS Studio WebSocket v5.

Arsitektur & Kemampuan Inti

Dirancang modular agar AI dapat mengamati permainan, membantu aksi dengan aman, dan mengelola siaran live Anda.

01 • PUSTAKA & ADAPTOR

Deteksi Steam & Profil Game

Memindai library Steam lokal (appmanifest_*.acf) tanpa meminta login Steam dan menerapkan profil kontroler aman berbasis allowlist per genre.

02 • AI & PENGAWASAN

Kendali Bertingkat L1 / L2 / L3

AI Brain membaca kondisi gameplay melalui Python Vision Worker dengan kontrol manusia penuh: L2 Wajib Persetujuan, Ambil Alih Kontrol, dan Emergency Stop instan.

03 • STUDIO SUARA & SIARAN

OBS WebSocket & VoxCPM 2.0

Mengendalikan adegan OBS Studio, menyimpan Stream Key YouTube/Twitch secara terenkripsi di OS Keychain/Credential Manager, serta komentar suara Bahasa Indonesia.

Panduan Konfigurasi Lengkap

Langkah ringkas untuk menghubungkan OBS Studio, izin macOS, Steam, AI Brain, dan Voice Studio.

1. Setup OBS Studio, YouTube Live, & Twitch

  1. Buka OBS Studio 28+ → Tools → WebSocket Server Settings → centang Enable WebSocket server pada port 4455.
  2. Di menu Studio Siaran pada Ngegame, klik Hubungkan OBS WebSocket.
  3. Simpan Stream Key YouTube atau Twitch ke Manajer Kredensial sebelum menekan Mulai Siaran.

2. Izin Wajib macOS (System Settings)

  1. Buka System Settings → Privacy & Security di macOS.
  2. Aktifkan Ngegame pada Screen & System Audio Recording untuk Monitor Visi.
  3. Aktifkan Ngegame pada Accessibility dan Input Monitoring agar Kendali AI dapat mengirim input aman saat diizinkan.

3. Setup Pustaka Game Steam

  1. Pastikan Steam Client sudah terpasang di perangkat Anda.
  2. Buka menu Pustaka Game di Ngegame lalu klik Pindai Pustaka.
  3. Ngegame hanya membaca berkas appmanifest_*.acf lokal tanpa meminta kata sandi Steam.

4. Konfigurasi AI Brain (Ollama / OpenAI)

  • Ollama (Lokal): Jalankan layanan Ollama lokal untuk penalaran gratis di perangkat sendiri.
  • OpenAI (Cloud): Masukkan API Key langsung melalui menu Kendali AI untuk model vision cloud.
  • Gunakan mode L2 Wajib Persetujuan untuk meninjau setiap aksi AI sebelum dijalankan.

5. Studio Suara AI (VoxCPM 2.0)

  • Gunakan panel Sampel Cloning Suara untuk memutar preset Bahasa Indonesia atau mengunggah audio referensi (.wav/.mp3).
  • Seluruh sampel & hasil cloning tersimpan permanen di folder userData lokal.
