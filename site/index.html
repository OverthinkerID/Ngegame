Panduan Konfigurasi & Troubleshooting

Langkah cepat menyiapkan layanan pihak ketiga dan izin sistem operasi agar seluruh fitur berjalan penuh.

1. Setup OBS Studio, YouTube Live, & Twitch

  1. Buka OBS Studio 28+, masuk ke menu Tools → WebSocket Server Settings, lalu centang Enable WebSocket server pada port 4455.
  2. Di menu Studio Siaran pada Ngegame, klik Hubungkan OBS WebSocket.
  3. Untuk error Stream key belum dikonfigurasi: salin Stream Key dari YouTube Studio (Go Live) atau Twitch Creator Dashboard, lalu simpan di kartu Manajer Kredensial (tersimpan aman di OS Keychain / Windows Credential Manager).

2. Izin Wajib macOS (Screen Recording & Accessibility)

  1. Buka System Settings → Privacy & Security di macOS.
  2. Aktifkan Ngegame pada bagian Screen & System Audio Recording agar Monitor Visi dapat menangkap layar game.
  3. Aktifkan Ngegame pada bagian Accessibility dan Input Monitoring agar kontroler AI dapat mengirim input aman saat izin L1/L2 disetujui.
  4. Jika aplikasi dibuka pertama kali tanpa Apple Developer signing, klik kanan aplikasi → pilih Open.

3. Setup Pustaka Game Steam

  1. Pastikan Steam Client sudah terpasang dan minimal satu game terinstal.
  2. Buka menu Pustaka Game di Ngegame lalu tekan Pindai Pustaka.
  3. Ngegame membaca berkas appmanifest_*.acf secara lokal tanpa meminta kata sandi akun Steam Anda.

4. Konfigurasi AI Brain & Izin L1 / L2 / L3

  • Ollama (Lokal): Jalankan Ollama di perangkat Anda untuk penalaran AI gratis tanpa API cloud.
  • OpenAI (Cloud): Opsional sebagai cadangan bila Ollama tidak aktif.
  • L1 / L2 / L3: Mulai selalu dengan L2 Wajib Persetujuan untuk menguji aksi AI dengan aman, atau tekan Emergency Stop kapan saja.

5. Studio Suara AI (VoxCPM 2.0)

  • Gunakan panel Sampel Cloning Suara untuk menguji preset narator Bahasa Indonesia atau mengunggah audio referensi (.wav/.mp3).
  • Apabila server VoxCPM 2.0 lokal belum berjalan di port 8000, aplikasi otomatis memakai mekanisme cadangan lokal tanpa mengganggu game.
